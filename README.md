# coldworld2000

После Google-входа слова и переводы сохраняются в Cloud Firestore и автоматически синхронизируются между устройствами. Без входа доступен отдельный локальный словарь. Его слова можно явно загрузить в аккаунт кнопкой над списком. Публичный сайт: https://103010ya.github.io/coldworld2000/ . После входа перевод работает через Firebase Cloud Functions, независимо от локального компьютера.

## Запуск

Нужен Node.js 22 или новее:

```sh
npm start
```

Отдельный ключ Gemini нового проекта хранится в `~/.config/coldworld2000/gemini-key`, вне папки сайта. Можно переопределить путь через `GEMINI_KEY_FILE` или передать ключ через `GEMINI_API_KEY`.

Открыть `http://localhost:8001` на компьютере или его Wi-Fi-адрес с портом `8001` на телефоне. Обычный сервер Python не выполняет перевод.

Firebase-проект: `coldworld2000`. Google-вход включён. Настройки находятся в `firebase-config.js`, настройки провайдера — в `firebase.json`. База `words`: Enterprise Native Mode, Сеул (`asia-northeast3`), включены обновления в реальном времени. Личная коллекция: `users/{uid}/words`. Правила проверяют владельца, структуру разбора, размеры полей и неизменность исходного ввода и даты создания. Для синхронизации нужен интернет; успешное сохранение подтверждается сервером. Данные прошлых проектов не переносятся.

## Формат перевода

Русский, английский или корейский ввод → корейская словарная форма и русский перевод. Страница показывает перевод, значение, использование, формальность и четыре примера. Схема, инструкции и проверка ответа находятся в `translation-schema.mjs`. Используется существующая модель прототипа `gemini-3.5-flash-lite`.

Ключ Gemini хранится в Firebase Secret Manager и не попадает в браузер или репозиторий. Облачная функция `translateWord` (Сеул) принимает идентификатор слова, проверяет владельца через Google-вход, читает исходный ввод из базы `words` и сохраняет результат. Лимит — 100 успешных переводов в сутки на аккаунт; один одновременный перевод на аккаунт. Ошибки не увеличивают счётчик; повторяются только ответы Gemini 500/502/503/504.

GitHub Actions публикует только файлы интерфейса из `dist`, собранные через `node scripts/build-pages.mjs`. Серверный код и служебные файлы в сайт не включаются. Локальный сервер Python не поддерживает гостевой перевод; для локальной разработки используйте `npm start`.

Проверки: `npm test`.
